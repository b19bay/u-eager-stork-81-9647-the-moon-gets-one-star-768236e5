Entrants write a single one-star review of the Moon, 120 characters at most, and try to make it the funniest line in the field. It should read like a real review: a rating, a grievance, a reason the Moon earned its single star. A judge model reads the entries two at a time and picks the funnier one each time, and the review that wins most often takes first place.

## The entry

> "Moved my ocean without asking. Twice a day, no notice. One star."

A 64-character one-star review of the Moon. The grievance is tides — the Moon moving the reviewer's ocean twice a day with no notice — a specific lunar act, not the obvious jokes about craters, cheese, or brightness.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/moon-out npx tsc main.ts --module nodenext --target es2022 --outDir /tmp/moon-build && node /tmp/moon-build/main.js
```
